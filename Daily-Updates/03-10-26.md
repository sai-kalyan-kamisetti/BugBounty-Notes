
 
## Program Info
 
- **Scope:** All domains in scope, *except* third-party domains hosted on AIG infrastructure.
- **Required testing header** (set via Burp Match & Replace):
```
  Type: Request header
  Match: ^User-Agent.*$
  Replace: User-Agent: aigrdpresearcheryourh1username
```
- **Target:** [https://www.aig.com](https://www.aig.com/)
---
 
## Reconnaissance
 
Manual walkthrough of the AIG website — initial observations:
 
- URL/path naming convention is consistently **lowercase, dash-separated** across sections.
- Site uses cookies.
- Found **6 login portals**; 5 are publicly reachable, 1 returns Access Denied. Possibly gated by user category/role.
- AIG operates in ~190 countries, each with its own regional domain following the pattern `aig.{country_code}` (e.g. `AU` → Australia, `MY` → Malaysia).
- Homepage includes a downloadable PDF and embedded videos (played in-page, not redirected).
